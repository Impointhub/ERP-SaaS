# v1.0.0 - Initial Release

## SMART Goals&#x20;

**Spesific :** &#x20;

* cloning the system and mechanism of ERP used in V1 Point ERP (a version that has been used by real users for daily accounting records), and develop the product in new environment with the same customer journey to the V1 Point ERP

**Measurable:**&#x20;

* &#x20;an ERP app is built that fulfill 6 criteria: scalable, usable, secure, observable, maintainable, reliable

**Achievable:**

* steps should follow the SOP in place

**Relevant :**&#x20;

* &#x20;an ERP system to be used long term

**Time Bound :**&#x20;

* &#x20;30 / 11/ 2026
